# AGENTS.md

## Project Technology Stack

This project must use the following technologies:

* Node.js
* JavaScript (ES6+)
* HTML5
* CSS3

## Strict Requirements

* DO NOT use TypeScript under any circumstances.
* DO NOT create .ts or .tsx files.
* DO NOT install TypeScript dependencies.
* DO NOT generate TypeScript interfaces, types, enums, or declarations.
* DO NOT convert JavaScript files to TypeScript.
* All code must be written in plain JavaScript.

## Frontend Standards

* Use semantic HTML whenever possible.
* Use vanilla CSS or CSS Modules.
* Prioritize responsive layouts.
* Follow accessibility best practices.
* Keep the interface lightweight and performant.

## Backend Standards

* Use Node.js for server-side code.
* Prefer Express.js when a backend framework is required.
* Use async/await instead of callbacks whenever possible.
* Keep APIs RESTful and well organized.

## Code Quality

* Write clean and readable code.
* Use descriptive variable and function names.
* Avoid unnecessary dependencies.
* Keep files modular and reusable.
* Add comments only when they improve understanding.

## Project Structure

Recommended structure:

/public
/css
/js
/routes
/controllers
/services
/views

## AI Development Rules

Before generating code, verify that:

1. No TypeScript is being used.
2. No .ts or .tsx files are created.
3. Only JavaScript, HTML, CSS, and Node.js are used.
4. Generated code follows the project structure defined above.

If a solution would normally use TypeScript, replace it with an equivalent JavaScript implementation.
